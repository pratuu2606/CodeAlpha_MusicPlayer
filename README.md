# 🎵 Music Player

A simple and responsive music player website created using HTML, CSS, and JavaScript.

## ✨ Features

- Play and pause songs
- Next and previous buttons
- Volume control
- Music progress bar
- Playlist
- Album covers
- Responsive design
- Keyboard controls

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
